# Banco de Dados Hospitalar — hospital_aula2

## Descrição
Projeto acadêmico da disciplina de Banco de Dados. O objetivo é organizar informações de um hospital por meio de tabelas relacionadas.

## Entidades
- Pacientes
- Médicos
- Consultas
- Exames
- Medicamentos

## Tecnologias
- MySQL
- SQL
- GitHub

## Como executar
1. Abra o MySQL Workbench.
2. Abra o arquivo `hospital_aula2.sql`.
3. Execute o script para criar o banco de dados e suas tabelas.

## Relacionamentos
- Um paciente pode ter várias consultas.
- Um médico pode realizar várias consultas.
- Um paciente pode ter vários exames.
- Um médico pode solicitar vários exames.
